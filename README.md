# Stoklytics

Um ERP web para lojas de moda, criado para reunir em um só lugar o controle de estoque, as vendas e a rotina da loja.

## Funcionalidades

- Painel com indicadores de vendas e estoque
- Cadastro de produtos, categorias e tamanhos
- Ponto de venda com cupons, descontos e diferentes formas de pagamento
- Gestão de clientes, vendedores e metas
- Controle de fluxo de caixa
- Relatórios e exportação de dados
- Temas claro e escuro

## Tecnologias

O front-end foi desenvolvido com HTML, CSS e JavaScript. O projeto também conta com uma API feita em Node.js e Express, e armazenamento de dados em SQLite.
